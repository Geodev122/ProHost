# Reel sources

Deterministic HTML animations rendered frame by frame (`window.render(t)`).

- `reel.js`: second-person template for posts 3–10 (`mode: "renter" | "host"`). Each `post*.html` only sets `window.P`.
- `post1_hosts.html`, `post2_app.html`: standalone timelines.
- `base.css`: brand tokens and the Instagram safe zone (`#stage` = 1080×1350 design, scaled to 92 %, top 250 px).
- `bg` → `../bg` (photo backgrounds, generated by the "Marketing backgrounds" workflow).

Render (needs Python with `playwright imageio-ffmpeg pillow` and Chromium):

    python render.py post7_hotel.html 16 30                 # → out/post7_hotel.mp4, _cover.png, _grid.png
    python render.py post7_hotel.html 16 30 3.5,9.5,14      # preview frames only

Combine with the voice (from the "Marketing voiceovers" workflow):

    ffmpeg -i ../post7_hotel.mp4 -i ../voice/post7_hotel_voice.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -t 16 ../final/post7_hotel_final.mp4
