One row per unit (screen, sheet/dialog, component group, logic file). A unit is done only when every column is ticked and the owner has seen the contact sheet for phase gates.

Protocol: **Learn** (read source, list states/strings/callables) → **Plan** (5-line card) → **Execute** (Android first) → **Compare** (unit tests, golden diff vs `kmp-golden-v1047`, string/plural count, behaviour tests, Android | iOS sheet) → **Confirm** (deviations listed in DECISIONS.md) → **Proceed**.

Kotlin file is missing from it). It lists all 147 files: 130 in-scope units (A1/A2/B/C) and 17 admin files (class X, owned by `ADMIN_PARITY.md` and the
adminWeb track). Class is an automatic first guess; the unit's *learn* step confirms or edits it (edits are preserved). Columns: **Goldens** = the file-name
prefixes in `refs/design-shots/golden-v1047` that must stay pixel-identical (`diff_shots.py --only`), **Tests** = unit tests that prove the logic,
**Android diff = 0** / **iOS sheet** = ticked when verified, **Status** = todo → learn → planned → ported → compared → done (or `adminWeb`).
